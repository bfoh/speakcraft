# SpeakCraft independent-rating worksheet template

**For a future consented study only. No rating data is collected by the current app.** Use [rubric draft v0.1](ASSESSMENT_RUBRIC_DRAFT.md) and a locally approved task/rubric version. Two trained raters should fill this separately without seeing each other's decisions or an ASR transcript first. Record the stimulus actually delivered; never infer missing help or prompt replays.

| Field | Value |

## Independent rating record, one per task and rater

| Field | Value |
| --- | --- |
| Rater ID (pseudonymous), rating date | |
| Audio quality: clear / partly audible / unusable, with reason | |
| Evidence state: valid attempt / `NE` | |
| If `NE`: missing, inaudible, incomplete prompt, interrupted or other reason | |
| Outcome if valid: `0`, `1` or `2`, using the task anchor | |
| Exact audible evidence supporting `0` or `1` | |
| Meaning understood and task act completed | |
| Listening facts, if applicable | |
| Intelligibility event only if meaning changed or was blocked; note replay | |
| Support language used and meaning conveyed, if applicable | |
| One short actionable learner feedback point, if requested | |

Listen once for meaning, then allow at most one neutral replay to resolve ambiguity. Do not convert missing or unusable audio (`NE`) to a zero. A Ghanaian English accent difference alone is not an intelligibility issue. Mark technical uncertainty and ask the study lead rather than guessing. Do not treat the worksheet as vocational certification.

## Adjudication and reporting

The study lead pairs the two de-identified rows by random attempt ID and task ID after both are locked. Preserve each original rating and the discussion outcome. Report, by task, valid/`NE` counts, exact and adjacent agreement, disagreement reasons, prompt/stimulus mode and audio-condition patterns. Set any release thresholds **before** seeing the results with the assessment specialist. Compare only the four mapped Day-1/Day-5 customer acts after local reviewers approve the mapping; `baseline-introduction`, `baseline-picture`, `baseline-procedure` and `day5-close` have no pair. A small 5–10 learner feasibility round is for task and usability defects, not a population-level score scale.

The consent record and the key linking a random ID to a learner must live separately from the audio and rating rows. Storage, access, encryption, deletion and withdrawal procedures are unresolved and must be approved before any recording is retained or shared. See [pilot readiness](PILOT_READINESS.md).

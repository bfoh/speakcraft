# Alpha curriculum

Edit `alpha.json`, then run from the repository root:

```sh
python3 scripts/sync_curriculum.py
python3 scripts/sync_curriculum.py --check
```

The five day titles/objectives follow blueprint section 11. The thirty-day sequence is not the Alpha sequence. Day 1 is implemented; Days 2–5 are data seeds for future sprints. Examples and durations are editorial implementation content and need educator review before a learner pilot.

Stable lesson/prompt IDs allow future attempts to reference versioned curriculum without widget text as identifiers. Change the content version when making meaningful editorial changes. Never use visitation as proof of mastery or completion.
